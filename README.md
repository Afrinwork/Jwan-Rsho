# Rsho

Private iPhone order-management app built with Expo, React Native, TypeScript, Expo Router, and Firebase.

This project uses Expo SDK 57. To open it in Expo Go for SDK 57, install dependencies with `npm install`, stop any running Expo server, then run `npm run expo-go` and scan the new QR code on your iPhone. The command clears Metro's cache.

Use Node.js 24 LTS (24.15.0 or newer) for compatibility with npm and the Firebase tooling.

Start here before coding:

- `CODEX_MASTER_PROMPT.md`
- `app/` for routes only
- `src/features/` for feature logic
- `src/repositories/` for data access
- `src/services/` for isolated cross-feature services
